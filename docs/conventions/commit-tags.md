# Commit Tags Quick Guide

## Etiquetas y uso

* **feat** → nueva funcionalidad en el sistema
* **fix** → corrección de errores o bugs
* **refactor** → mejora interna sin cambiar comportamiento
* **docs** → documentación del proyecto

---

## Ejemplos rápidos

```bash
feat: add turno module
fix: resolve validation error
refactor: improve database relations
docs: add commit guidelines
```

---

## Regla rápida

 Si dudas:

* ¿agregué algo? → **feat**
* ¿arreglé algo? → **fix**
* ¿mejoré código? → **refactor**
* ¿es documentación? → **docs**
* ¿no terminé? → **feat (in progress)**
